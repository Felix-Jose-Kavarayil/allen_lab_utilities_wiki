# Allen Lab Utility Wiki

This repository contains documentation, practical guides, and shared resources for members of the Allen Lab.

## Purpose

The repository provides a central location for information related to:

* Laboratory computing infrastructure
* Data storage and organization
* Network and NFS access
* Software installation and configuration
* Data analysis workflows
* Experimental procedures
* Frequently used commands
* Troubleshooting common technical problems

## Repository Structure

The documentation is organized into separate Markdown files and folders according to topic. Open the relevant `.md` file to view a guide.

## Using the Repository Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/allen_lab_utility_wiki.git
cd allen_lab_utility_wiki
```

Update your local copy:

```bash
git pull
```

Markdown files can be opened using a text editor such as Emacs:

```bash
emacs README.md
```

## Contributing

To add or update documentation:

1. Pull the latest version of the repository.
2. Create or edit the relevant Markdown file.
3. Review the instructions for accuracy.
4. Commit the changes with a clear description.
5. Push the changes to GitHub.

Example:

```bash
git add .
git commit -m "Update documentation"
git push
```

## Important Notes

* Do not upload passwords, access tokens, personal information, or other credentials.
* Do not upload confidential or sensitive research data.
* Verify commands and file paths before using them.
* Follow the laboratory’s data-management and security policies.
* Contact the repository maintainers if any instructions are unclear or outdated.

## Access

This repository is intended for authorized lab members and collaborators. Some procedures may depend on access to the laboratory network, servers, workstations, or storage systems.
